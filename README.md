GoMart – Grocery Shop Management System
 
## 📌 Project Overview
 
GoMart is a C# Windows Forms based Grocery Shop Management System developed to manage different operations of a grocery store efficiently.
 
The system provides modules for administration, product management, seller management, category management, sales management, and database connectivity.
 
---
 
## 🚀 Features
 
### Admin Management
- Add and manage administrators
- Manage administrator information
 
### Product Management
- Add new products
- Manage product information
- Update product details
- Product-related database operations
 
### Seller Management
- Add new sellers
- Manage seller information
 
### Category Management
- Add and manage product categories
- Maintain category information
 
### Sales Management
- Manage product sales
- Select products for selling
- Handle sales-related operations
 
### Database Connectivity
- SQL Server database integration
- Database connection through `DBConnect.cs`
- SQL scripts are included in the project
 
---
 
## 🛠️ Technologies Used
 
- C#
- .NET Framework
- Windows Forms
- Microsoft Visual Studio
- Microsoft SQL Server
